認定NPO法人五条クラブでは、学校・企業・自治体・各種団体を対象に、
アフリカ ( ウガンダ ) やネパールで行っている国際支援活動についての講演を実施しています。
現地での体験をもとに、「教育」「スポーツ」「国際協力」「SDGs」「ボランティア」などを、
写真や映像を交えながらわかりやすくお伝えします。
※ご希望に応じて講演内容を構成いたします。

  • 小学校 中学校 高等学校
  • 大学 専門学校
  • PTA
  • 自治体
  • 企業
  • ロータリークラブ
  • ライオンズクラブ
  • 青年会議所
  • 各種団体・サークル
  • スポーツが子どもたちの未来を変える
  • ウガンダに小学校をつくった理由
  • ネパールでのサッカーを通じた国際交流
  • SDGsを身近に考える国際協力
  • 一歩踏み出す勇気 〜挑戦から学んだこと〜
  • ボランティア活動が地域と世界をつなぐ

※テーマはご希望に応じて自由に構成いたします。

・ウガンダ、ネパールの現状　・教育支援、スポーツ支援の取り組み
・現地での体験談　・写真と動画による紹介　・質疑応答

・60分　・90分
※ご希望に応じて調整いたします。

・会場開催　・オンライン開催　・ハイブリッド開催
全国どこでも対応可能です。

世界には、スポーツや教育を必要としている子どもたちがいます。
現地でのリアルな体験を通して、「自分にもできること」を考えるきっかけとなる講演をお届けします。
皆さまとともに、世界や未来について考える時間を共有できることを楽しみにしております。
